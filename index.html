Import your spreadsheet

  1. In Google Sheets: File → Download → Microsoft Excel (.xlsx)
    Comma-separated values (.csv) works too.
  2. Columns must be in this order:
    A SKU B Item ID C Before Price D During Incentive
    Only SKU is required — Item ID and prices can be blank (prices start at 0.00). A header row is fine — it's skipped. Extra columns ($ Change, % Change, …) are ignored; those recompute here. Not sure about the layout? Download a blank template.
  3. Optional commission columns:
    Regular Commission During Incentive Commission
    Found by their header names, so they can sit in any column. Rows without them default to 6% / 2%. These fill the commission columns in the exported sheet.
  4. Pick the downloaded file, then choose Add to bottom (rows already in the table are skipped) or Replace table.

Tip: you can also copy rows in Google Sheets and paste them straight into the table with Ctrl+V — no file needed.

Import from Seller Center

Walmart's API doesn't report an item's strategy, minimum or maximum, so the app reads them from the file Seller Center lets you download.

  1. In Seller Center go to Pricing → Automate pricing and open the strategy.
  2. Clear the search box so every item is listed, then press Download.
  3. Type the strategy's name below and choose the downloaded file.
