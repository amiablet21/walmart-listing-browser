Import your spreadsheet

  1. In Google Sheets: File → Download → Microsoft Excel (.xlsx)
    Comma-separated values (.csv) works too.
  2. Columns must be in this order:
    A SKU B Item ID C Before Price D During Incentive
    Only SKU and Item ID are required — prices can be blank (they start at 0.00). A header row is fine — it's skipped. Extra columns ($ Change, % Change, …) are ignored; those recompute here.
  3. Optional commission columns:
    Regular Commission During Incentive Commission
    Found by their header names, so they can sit in any column. Rows without them default to 6% / 2%. These fill the commission rates in the "For Walmart rep" export.
  4. Pick the downloaded file, then choose Add to bottom (rows already in the table are skipped) or Replace table.

Tip: you can also copy rows in Google Sheets and paste them straight into the table with Ctrl+V — no file needed.
